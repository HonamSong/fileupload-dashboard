비어 있으면 모든 IP 허용. 입력하면 목록의 IP만 대시보드에 접근할 수 있습니다.

          

            

            
          

          

        

        

          
✕ Block (차단 목록)

⚠ 주의: UI 허용 목록에 본인 IP를 넣지 않으면 대시보드에서 잠깁니다. 잠겼을 때는 컨테이너에 환경변수 IP_GUARD_DISABLE=1 을 주고 재시작하면 모든 IP 제한(UI 접근 제한 + API 엔드포인트 제한 + 자동/수동 차단 목록)이 일시적으로 전부 해제됩니다. 그 상태로 로그인해 허용 목록을 고쳐 저장한 뒤, 이 화면 상단의 "지금 IP 제한 다시 적용" 버튼으로 재시작 없이 제한을 다시 켤 수 있습니다. (env 변수는 편할 때 제거) (도커 환경에서는 클라이언트 IP가 게이트웨이로 보일 수 있으니 반드시 프록시에서 X-Forwarded-For 전달)
